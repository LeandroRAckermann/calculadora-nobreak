# Calculadora de Nobreak

Projeto desenvolvido em Python para calcular a capacidade necessária de um banco de baterias para um nobreak.

## Funcionalidades

O programa recebe:

- Potência dos equipamentos em Watts
- Tempo de autonomia desejado
- Tensão do banco de baterias

E calcula:

- Energia necessária
- Capacidade do banco em Ah
- Quantidade de baterias de 12 V

## Tecnologias

- Python
- Tkinter
- Git
- VS Code

## Como executar

1. Instale o Python.
2. Clone este repositório.
3. Abra a pasta do projeto.
4. Execute o arquivo principal:

```bash
python cal_nobreak.py
